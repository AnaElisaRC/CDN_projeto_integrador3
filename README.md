## 📌 Visão Geral

O projeto desenvolveu uma proposta de **automação para a análise de dados do Plano de Gestão Anual (PGA)** das Fatecs. O objetivo foi substituir a leitura manual de relatórios em PDF por um fluxo automatizado de dados e dashboards interativos.

---

## 📁 O que foi Desenvolvido

- **Modelagem de Banco de Dados:** Criação de modelos conceitual, lógico e scripts SQL em SQLite para estruturar os dados do PGA.
- **Pipeline de ETL:** Extração de dados de PDFs com Python (`PyMuPDF`), transformação e limpeza (`Pandas`) e modelagem em Esquema Estrela.
- **Arquitetura (Modelo C4):** Mapeamento dos componentes do sistema (Data Lake, Data Warehouse e BI).
- **Dashboard em Power BI:** Visualização gráfica dos investimentos, custos por projeto, carga horária e principais problemas institucionais.

---

## 🛠️ Tecnologias Utilizadas

- **Linguagens & Bibliotecas:** Python (`PyMuPDF`, `Pandas`), SQL
- **Bancos de Dados:** SQLite, PostgreSQL
- **Visualização de Dados:** Microsoft Power BI
